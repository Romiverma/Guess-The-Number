# 🎯 Guess The Number Game

A fun and interactive number guessing game built using **HTML, CSS, and JavaScript**. Challenge yourself to guess the secret number between 1 and 100 in the fewest attempts!

## ✨ Features

- 🎯 Random secret number generation (1–100).
- ⬆️ Shows hints when your guess is too low.
- ⬇️ Shows hints when your guess is too high.
- 🔢 Tracks the number of attempts.
- 🏆 Saves your best score using Local Storage.
- 🔄 Reset button to start a new game.
- ✅ Validates user input.
- 📱 Responsive design for mobile and desktop.
- 🎨 Modern dark-themed UI with gradient effects.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling, gradients, animations and responsive design.
- **JavaScript** – Game logic, DOM manipulation and event handling.
- **Local Storage** – Saves the best score.

## 🎮 How to Play

1. Open the game in your browser.
2. Enter a number between 1 and 100.
3. Click on **Check My Guess**.
4. Follow the hints:
   - Too Low → Try a higher number.
   - Too High → Try a lower number.
5. Guess the correct number to win!
6. Try to beat your best score.
